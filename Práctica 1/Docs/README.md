# Sistemas Operativos - Universidad de Alicante

Este repositorio contiene el código fuente, las prácticas y los ejercicios correspondientes a la asignatura de **Sistemas Operativos**. 

El objetivo principal de estos proyectos es aplicar los conceptos teóricos sobre la gestión del sistema, control de procesos, comunicación inter-procesos y llamadas al sistema (system calls) mediante programación a bajo nivel.

## 🛠️ Tecnologías y Entorno

* **Lenguaje:** C y C++
* **Entorno de desarrollo:** Linux (Arch Linux)
* **Control de versiones:** Git y GitHub

## 📂 Estructura del Repositorio

El material está organizado en directorios según las sesiones y bloques de la asignatura:

* **`Práctica 1/`**: Ejercicios introductorios, manejo de archivos y llamadas al sistema.
* **`Práctica 2/`**: Control de procesos, jerarquías y gestión de memoria.
* *(Se irán añadiendo más directorios conforme avance el curso)*
